# Flappy-Bird-Arcade-Remix
New version of Flappy Bird, recreate with Claude and ChatGPT

You can play on a web browser via this link: http://verdant-gaufre-1ec0f1.netlify.app

Note: it is possible that on some devices or browsers such as Safari, the singing mode does not work or does not work poorly, for the moment I cannot solve the problem

The project is basic in French, on the Web and HTML version you can directly change the language via the button 🌐

Only French and English are supported for the moment...
